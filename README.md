# al.avo - Premium Avocado Brand Website

A modern, single-page website for **al.avo**, a premium avocado-based juice and treats brand located in Illathupady, Edavanakkad.

## 🥑 About

al.avo specializes in fresh, healthy avocado-based beverages and treats. This website serves as a coming-soon landing page to build anticipation for the brand's grand opening.

## 🚀 Features

- **Modern Single-Page Design**: Smooth scrolling navigation between sections
- **Responsive Layout**: Optimized for all devices (desktop, tablet, mobile)
- **Brand-Focused Design**: Green and white color scheme with avocado elements
- **Interactive Components**: Hover effects, animations, and smooth transitions
- **Social Media Integration**: Links to Instagram, Facebook, and WhatsApp

## 🎨 Design

### Color Palette
- **Primary Green**: `#4F7942` (Fern Green)
- **Accent Green**: `#87A96B` (Avocado Green)
- **Background**: `#FFFFFF` (White)
- **Accent Background**: `#F5FFFA` (Mint Cream)

### Typography
- **Font Family**: Inter (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700

## 📱 Sections

1. **Hero Section**: Brand introduction with "Something New is Coming" message
2. **About Section**: Brand story and core values
3. **Menu Section**: Preview of avocado-based products (coming soon)
4. **Contact/Footer**: Location, social media, and contact information

## 🛠 Tech Stack

- **Framework**: Next.js 15.3.3 (App Router)
- **Styling**: Tailwind CSS 4
- **Language**: JavaScript (No TypeScript)
- **Icons**: Custom SVG icons and avocado emoji
- **Fonts**: Inter from Google Fonts

## 🏃‍♂️ Getting Started

1. **Install Dependencies**:
   ```bash
   yarn install
   ```

2. **Run Development Server**:
   ```bash
   yarn dev
   ```

3. **Open in Browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

## 📦 Build for Production

```bash
yarn build
yarn start
```
